# ativedade-de-progama-ao
O projeto Criptografando Letras é uma aplicação web desenvolvida em HTML, CSS e JavaScript para demonstrar o funcionamento da Cifra de César, um método básico de criptografia. A aplicação permite que o usuário digite uma mensagem e visualize sua versão criptografada com um deslocamento de três posições no alfabeto, proporcionando uma experiência.
